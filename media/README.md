All included media is synthetic and safe for a controlled demonstration.

- `camera_1_clip.mp4` and `camera_2_clip.mp4` contain a programmatically drawn
  car, mock South African-style plate `AB12CDGP`, and simple person silhouette.

Replace these fixtures only with authorized vehicles and consented participants.
